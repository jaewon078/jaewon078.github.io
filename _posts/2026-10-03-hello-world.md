This is an example post. Delete it or replace it with your own.

To write a new post, add a file to the `_posts/` folder named like
`YYYY-MM-DD-your-title.md`, with a short header at the top:

```markdown
---
title: My new post
---

Write in **Markdown** here.
```

Push it to GitHub and it'll show up on the site in a minute or so.

## Things you can use

- Headings, lists, [links](https://jaewon078.github.io), and `inline code`
- Images: `![alt text](/assets/images/photo.jpg)`
- Code blocks with syntax highlighting:

```python
def greet(name):
    return f"hello, {name}"
```

> And blockquotes, too.
